    steffen huck · an identification game

    Welcome to The Next Test

    Several explanations fit the facts. Choose experiments to find an exact answer—or discover why none is possible.

    Try to use as few experiments as you can. You can compare their predictions before running them.

    How to play

    Read the question and cards. One explanation is true. Each card gives a possible answer; the starting facts do not tell you which to trust.

    Select a test. The lines show which result each explanation predicts. Explanations reaching the same result would remain possible together. Previewing a test costs nothing.

    Run it. The true explanation determines the result. Cards predicting something else are ruled out. All results are exact, so repeating a test adds nothing.

    Give an answer. Open that tab and select a number. It is justified only if every remaining explanation agrees. If no available test can settle the number, choose the other option and compare two conflicting explanations.

    There is no time limit or experiment budget. After you finish, the game shows a shortest strategy that guarantees a justified conclusion. A favourable result may let you finish sooner.
